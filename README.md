# 火山噴火タイプ識別ガイド

ハワイ式・ストロンボリ式・プリニー式・超プリニー式など7種の噴火タイプを特徴から学び、4問の選択式クイズで自分で噴火タイプを識別できるインタラクティブガイド。有名火山の事例一覧と豆知識付き。

## 機能
- 7種の噴火タイプ（ハワイ式・ストロンボリ式・ブルカノ式・ペレー式・プリニー式・超プリニー式・水蒸気噴火）をカードで解説
- VEI（火山爆発指数）・溶岩タイプ・噴煙高度・特徴を視覚的に表示
- 4問の特徴選択クイズ（爆発の激しさ・溶岩流・火砕流・噴煙高度）から噴火タイプを識別
- 富士山・キラウエア・ベスビオ・桜島・御嶽山など12火山の事例テーブル
- VEI・火砕流・水蒸気噴火・溶岩タイプなどの豆知識コーナー
